### 1.1 已量化、可稽核的偏差

1. **Survivorship bias（無法量化，只能界定）**
   20 檔全部是「今天仍然掛牌上市」的股票。任何在 2024–2026 期間下市、被併購或
   曾因財務問題停止交易的公司都不在樣本內。因此本專案的絕對績效數字
   **系統性偏樂觀**，且偏樂觀的幅度**無法用現有資料估計**（除非拿到下市股資料，
   否則連「漏掉幾檔」都不知道）。這是本專案最重要的未解限制。

2. **新聞情緒因子在歷史回測中實質失效（可量化）**
   `news` 僅涵蓋 8 個日曆日的資料，而特徵工程的原始行為是
   `df["news_sentiment"] = df["w_score"].fillna(0.0)` —— 也就是在歷史面板中
   這個因子幾乎恆為 0，卻仍以 **0.10 的權重**參與 `WEIGHTS` 的標準化分母。
   後果有兩層：
   - 它不提供資訊（P2.3 診斷：有效交易日 0~2 天，判定「樣本不足」）；
   - 它稀釋其他因子（分母固定 −0.10，等於其他因子被縮小約 10%）。
   P2.3 也顯示 `score` 的 IC（h=5 為 +0.0705）低於單一最強因子
   月營收 YoY（+0.0987），稀釋效果與此一致。

3. **新聞資料的可追溯性為零（P2.7 實測）**
   不只「涵蓋範圍小」，而是**根本無法判定這 237 筆是怎麼來的**：
   - 舊 schema 沒有抓取狀態欄位；舊程式的 `ok` 是硬編碼常數，因此
     `ingest_log` 的「163 筆全部成功、0 筆失敗」**不可採信**；
   - 舊程式在發布時間取不到時以**抓取當日**代替，故連「哪些 `published`
     是來源真實日期」都不可得。

   實測（`cli datacheck`）：**不可追溯率 100%、抓取成功率為「無可判定紀錄」**。
   已一律標為 `unknown`，**不以推測補造成功狀態**。
   這使新聞因子的可信分母實質上不存在 → **在補到可信的跨期資料之前，
   不應評估或調整新聞因子**（比 B17 的權重問題更上游）。

4. **樣本期間不足以支持任何「穩定」的市場結論（可量化）**
   1.93 年、486 個交易日、單一多頭市況。P2.3 的分段結果顯示
   `score` 的 IC 由 train 的 +0.1170（p=0.0010）退化到 valid 的 +0.0502（p=0.30）、
   test 的 −0.0104（p=0.74）。這**不是**「策略有效但成本高」，而是
   「資訊本身在樣本外無法穩定重現」。

## 3. 遷移方案（分階段；本階段只做 A，B 之後需使用者決定）

### A. 免費、可立即執行（不需採購）
1. **官方下市清單**：接 TWSE `suspendListingCsvAndHtml` 與 TPEx 終止上櫃頁面，
   建立 `delisted` 資料表，至少能量化「樣本期間內有多少檔下市」。
2. **延長歷史**：同一組 FinMind 資料集把 `lookback_years` 由 2.0 拉長，
   覆蓋 2018 以後的**空頭與高波動期間**（2020 肺炎、2022 升息、2025 關稅）。
   注意：FinMind 免費限額 300～600 次/小時，20 檔 × 多資料集需分批。
   這些歷史用 `store.write_df` 冪等寫入，可中斷續傳。
3. **新聞因子（P2.7 已把「資料可不可信」處理完，P2.6 已證偽「改權重」）**：
   - **P2.7（本階段）**：修正觀測能力——新聞失敗不再被記為成功、
     四態可分、時間戳不臆測、舊資料一律標 `unknown`；
     並新增 `cli datacheck` 產出每日筆數、情緒覆蓋率與抓取成功／失敗率。
     這是**可觀測性**的改善，**不是預測能力的改善**。
   - **P2.6**：消融驗證（`twstock/ablation.py`）顯示分母效應會改變排名
     （僅 80.9% 交易日相同），但 86 個配對假設校正後無一顯著、
     test 段 A ≡ B ≡ D 完全相同；而**分子效應根本無法估計**
     （29 個非 0 觀察全在無前瞻報酬的樣本末端）→ **不改權重**。
   - **因此現在的工作重點不是改權重，而是「把資料累積起來」**：
     Google News RSS 只能取得最近 `days` 日、**無法回溯歷史**，
     所以必須先改成**按日累積寫入並長期保存**（或以採購方式取得歷史新聞），
     否則任何新聞因子的重評都沒有可信的分母。
4. **股票池擴充**：改用 FinMind `TaiwanStockInfo` 取得全市場清單並依市值排序取樣，
   同時**保留歷史成員**（今天的 20 檔不會永遠是未來的成分）。

### B. 需要採購或授權評估（BLOCKED，待使用者決定）
5. **TEJ / TQuant Lab**（首選評估對象）：唯一已查證同時提供下市股與
   逐日台灣 50 成分旗標者。建議先確認：(a) 學術／商業授權範圍、
   (b) 可否匯出衍生資料、(c) 最低期間方案是否足以覆蓋一個完整多空循環。
6. **CMoney / Fugle**：作為價格與籌碼的交叉驗證來源，而非 PIT 成分來源。

### C. 不建議
7. 以「今天的成分股」回推歷史成分（會製造另一種 forward-looking bias）。
8. 以 0050 目前的持股清單代替歷史成分。
9. 在未評估授權與可匯出性前購買任何資料。

### 1.2 新聞資料的可追溯性（P2.7 實測）

修復前的問題鍵（全部有程式碼位置）：新聞寫入路徑硬編碼 `ok=True`；
`feedparser` 在網路失敗時不撔例外而回傅空 entries（失敗＝沒有新聞）；
發布時間取不到時以「今天」代替。詳細缺陷編號（D16–D19）與實測數據見
`docs/STATUS_REPORT.md` 附錄 L–Q。

修復後的分類（`python -m twstock.cli datacheck`）：

| 概念 | 表示方式 |
|---|---|
| 沒有新聞 | `ingest_run.status = success_empty`（來源正常、確實沒資料） |
| 新聞存在但情緒中性 | `success_with_data` ＋ `news.score_kind='neutral'` |
| 有有效情緒分數 | `success_with_data` ＋ `news.score_kind='scored'` |
| 抓取失敗 | `failed` ＋ `error_class` ∈ network／timeout／http_status／parse |
| 時間不明 | `timestamp_source='unknown'`，`published` 為 NULL，排除於衰減窗口 |
| 舊資料 | `provenance='unknown'`（不得計入成功率） |

實測現況：237 則全部 `provenance='unknown'`、`timestamp_source='unknown'`；
`score_kind` 為 183 `neutral`／54 `scored`（**僅分數欄位本身可重建**）；
有效情緒覆蓋率為「全部列 22.8%／可追溯列 無資料」。

> 使用警告：任何讀取 `news.published` 的下游都必須先檢查 `timestamp_source`，
> 否則會把可能是偽造的日期當成真日期。

### 1.3 新聞資料的新規則（P2.8，2026-10-16）

P2.8 **沒有、也無法**解決「RSS 不提供歷史與可靠發布時間」的來源限制；
它做的是讓**前向累積**可信且可稽核。下列規則自本階段起生效：

| 概念 | 表示方式 |
|---|---|
| 最早可用日（point-in-time） | `usable_from = max(published, fetched_at)`；兩者缺一即不可用 |
| 重複抓到同一則 | 不新增、不覆寫（`INSERT OR IGNORE`，首次寫入即定案） |
| 股票關聯可驗證 | `link_basis='title_match'`（標題含代號或公司名） |
| 股票關聯無法確認 | `link_basis` 為 `rss_query`（僅依查詢關聯）或 `unknown` |
| 可重現當初分數 | `source_version`＝寫入時的情緒規則版本 |
| 可回溯來源任務 | `run_id` → `ingest_run`（來源、任務、起訖、狀態、筆數、重試） |
| 往前累積的前瞻資料 | `research_cutoff` 每日切點（首次寫入即定案）＋凍結的 `spec_hash` |

**尚未解決（不得宣稱已解決）**：

1. **無穩定識別碼**：`news_uid` 只能採 guid → 正規化 link → content_hash
   三層回退；三者皆不可靠時無法保證跨來源同一則新聞會被合併。
2. **發布時間不可靠**：來源未提供時一律 NULL，不以抓取時間偽造；
   若來源提供錯誤的發布時間（晚於取得時間），該列一律排除於訊號路徑。
3. **無法回溯歷史**：只能往前累積；在累積到最低觀察期間（120 交易日，
   建議 250）之前，新聞因子**不得**拿去重評 B17，也不得重複使用已消耗的 test 段。
4. **單一來源、無備援**：公開 Google News RSS 無 SLA，失敗現已可區分
   （`error_class`），但沒有第二來源可交叉驗證同一則新聞。

## 4. 現階段結論的適用範圍（必須一起引用）

- 所有回測與診斷結果僅適用於：**2024-10-14 ~ 2026-10-13、這 20 檔、這段多頭市況**。
- **不得**以本專案任何數字宣稱代表台股市場整體、也不得宣稱策略具備獲利能力。
- 在取得下市股與歷史成分之前，**超額報酬的絕對水準不可信**；
  但「訊號在樣本外的 IC 無法穩定重現」與「成本與曝險結構主導結果」
  這兩項結論屬於**內部結構性發現**，不會被存活者偏差的方向反轉
  （存活者偏差會讓策略看起來*更好*，而不是更差）。
