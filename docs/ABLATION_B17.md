## 1. 實際分數公式與缺值機制

### 1.1 分數公式

`signals.score_row()`（生產路徑，`twstock/ablation.py` 的方案 `A` 與其**逐位元一致**，有測試保證）：

```
score = clip( Σᵢ∈可用 Wᵢ·vᵢ  /  Σᵢ∈可用 Wᵢ , −1, +1 )
```

- 只對「當列可用」的因子標準化；缺值因子不進入分子**也不進入分母**。
- `WEIGHTS` 12 項**實際總和 = 1.05**（`signals.py` 的註解寫「總和 = 1.0」，與實作不符；
  因會再標準化故不影響分數，但註解屬錯誤，另登錄）。
- 融合分數 `fuse_scores` 先做當日橫斷面排名百分位，故尺度不變；
  但本階段 ML 未啟用，`score` 即規則分數。

### 1.2 新聞因子的缺值機制

| 項目 | 數值 | 說明 |
|---|---|---|
| `news` 表 | 237 筆、8 個日曆日 | 2026-10-06 ~ 2026-10-13，**全在樣本最末端** |
| 佔價格日比例 | 5 / 534 交易日 = **0.94%** | 衰減窗口 lag 0/1/2 後仍僅覆蓋最末幾日 |
| `fillna(0.0)` 後非缺值列 | **9,719 / 9,719（100%）** | 因此 0.10 **恆入分母** |
| 其中有新聞記錄（presence=1） | 61 列 | 32 列情緒為 0、29 列情緒非 0 |
| 分子實際非 0 | **29 列** | 占全面板 0.30% |

**三態分類（方案 D 依據，已於 `build_features` 新增 `news_present` 欄位）**

| 狀態 | 意義 | 列數 |
|---|---|---:|
| `absent` | 沒有新聞（缺值）— **不得解讀為中性情緒** | 9,658 |
| `neutral` | 有新聞記錄但有效情緒值為 0 | 32 |
| `scored` | 有新聞且情緒值非 0 | 29 |

⚠️ **「沒有成功抓到新聞」無法表示**：`news` 表無抓取狀態欄位，且 `news_rss` 吞掉例外回傳空清單
→ 抓取失敗與「搜尋無結果」在現有 schema 下**不可分**。方案 D 只能區分上表三態中的
`absent` / `neutral` / `scored`，此為已知限制（需改 ingest 才能補，本階段不動）。

### 1.3 可用權重 W 的跨股票變動（本階段最關鍵的結構事實）

| 項目 | 數值 |
|---|---|
| `W_A` 範圍 | 0.53 ~ 1.05 |
| W 跨股票**變動**的交易日 | **483 / 486** |
| 理論尺度比 `den_b/den_a` 同日散布 | 均值 0.01343、最大 0.03634、散布為 0 者僅 3/486 日 |

**推論**：W 在同一天跨股票變動 → 分母從 `W_A` 改成 `W_A − 0.10` **不是**單一正比例常數，
而是**逐股不同**的倍率（0.811 ~ 0.905）。因此「移除一個值為 0 的因子」**不等於**純尺度縮放，
**排名可以真的改變**。這是本階段用實測推翻的先驗直覺。

## 2. 四個方案（＋一個分解控制組）

`parts` = 該列可用因子的 (鍵, 方向化值)；`W_A` = 含 news 的可用權重和。

| 方案 | 分子 | 分母 | 意義 |
|---|---|---|---|
| **A** 現行 | 含 news | `W_A` | 現行行為：缺值填 0.0，但 0.10 仍入分母 |
| **A\*** 控制組 | **不含** news | `W_A` | 與 A 的差異 = **純新聞分子項** |
| **B** 移除＋重新標準化 | 不含 news | `W_A − 0.10` | 把 news 完全排除，其餘權重重新標準化 |
| **C** 固定權重 | 不含 news | `1.0` | 不分攤重算，保留其他因子原始權重 |
| **D** 可用性閘門 | 有記錄才含 news | 對應可用權重和 | 缺值不計入，不冒充中性 |

**代數恆等式（clip 前實測，9,719 列全數通過）**

| 恆等式 | 最大誤差 |
|---|---|
| `A − A* = 0.10·v_news / W_A` | 4.163e-17（9,690 列新聞分子為 0 → 嚴格等於 0） |
| `den_b = W_A − 0.10` | 1.110e-16 |
| `C = B × den_b` | 5.551e-17 |

## 6. 結論：B17 是否真正影響策略選股？

### 6.1 兩個機制必須分開看

| 機制 | 可觀測性 | 範圍 | 後果 |
|---|---|---|---|
| **分子**（`fillna(0)` 把缺值當 0） | ❌ **不可估計** | 情緒非 0 僅 29 列，且所在區間**無前瞻報酬** | 無法用本資料評估其預測力 |
| **分母**（0.10 佔位） | ✅ 全樣本可觀測 | 9,719 列（100%） | 排名在 93/486 日改變，但幅度極小 |

### 6.2 是否為單一正比例常數？— **不是**

- 理論：`A = B × (den_b / den_a)`，其中 `den_b/den_a = 1 − 0.10/W_A`。
- 若 `W_A` 同日跨股為常數 → 排名必然相同（尺度不影響排名型策略）。
- **實測 `W_A` 在 483/486 日跨股變動（0.53~1.05）** → 該倍率逐股不同（散布均值 0.01343）
  → **不是單一正比例常數，排名真的會改變**。
- 已用合成資料以反例驗證：僅讓可用因子集不同，即可使 A 與 B 的名次互換
  （`tests/test_ablation.py::test_rank_changes_when_available_weight_varies_within_day`）。

### 6.3 是否值得修改正式策略？— **否**

依 §0 第 3、4 條的驗收標準（**只用 train/valid、需一致且可解釋的改善**）：

| 判準 | 結果 |
|---|---|
| train/valid 排名型指標（Rank IC）一致改善？ | ❌ A−B 符號翻轉（train +0.0006、valid −0.0009） |
| 配對 IC 差異顯著？ | ❌ 38 個假設，未校正顯著 **0** 個、BH 後 **0** 個 |
| 配對價差差異顯著？ | ❌ 38 個假設，**0 / 0** |
| 交易層級成本後日報酬一致顯著優於 baseline？ | ❌ 10 個假設，**0 / 0**；test 段差異嚴格為 0 |
| 是否利用 test 挑選方案？ | ❌ 未使用；且 test 已被先前階段消耗（見 §7） |

**結論：B17 會改變排名與成交，但在 train/valid 未顯示一致且可解釋的改善
→ 保留現行策略，記錄不確定性，不提出修改正式策略的建議。**

這與「為追求績效反覆調整測試集參數」的禁止事項一致：test 段 B 與 A 完全相同，
即使 train/valid 的點估計略優，也不足以支持改動。

| 「稀釋其他因子約 10%」 | 稀釋倍率**逐股不同**（0.811~0.905），因 W_A 跨股變動，**非單一常數** |
